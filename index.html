Panduan Bobot Poin & Metodologi Workload Analysis (WOLA)

Penilaian berbasis Jam Kerja Efektif Murni & Project Breakdown

🎯 1. Standar Konversi Poin WOLA

1 POIN WOLA = 2 JAM KERJA EFEKTIF MURNI. Standar beban ideal per staf adalah 20 Poin / bulan (40 jam kerja produksi murni di luar rapat & koordinasi). Peminjaman alat saja bernilai 0 Poin.

⚡ Estimasi Otomatis + Edit Kasie
  • Liputan & Desain Konten: 3 Poin / hari
  • Liputan Foto/Video / Studio: 2 Poin / hari
  • Desain Poster / Medsos Saja: 1.5 Poin
  • Peminjaman Alat: 0 Poin
  • Kasie dapat mengedit poin kapan saja via tombol ⚙️ Poin atau menu ACC / Atur.
🚦 Ambang Batas Kapasitas Staf
  • 🟢 ≤ 15 Poin: Kapasitas Aman (Longgar)
  • 🟡 16 – 25 Poin: High Utilized (Peringatan)
  • 🔴 > 25 Poin: Overload (Potensi Lembur / Perlu Rebalancing)
➕ Pemecahan Sub-Tugas Multi-Peran (Contoh: Sit-in Class)

Untuk kegiatan yang melibatkan lintas peran (Konseptor, Liputan, Desain Grafis, Editor Video), gunakan tombol ➕ Sub-Tugas di Room Kasie agar setiap peran mendapat baris, jadwal tayang, dan bobot poin tersendiri tanpa membebani staf lain secara ganda.
